How this stage initializes and trains

The completed native-v3 checkpoint supplies the rank-16 all-module LoRA matrices and the 256-dimensional pointer head. The balanced-v4 stage creates a fresh optimizer and schedule. Its unchanged recipe uses one epoch, learning rate 2e-5, batch 4 × accumulation 2, BF16 compute, FP32 stored weights and gradient checkpointing. It updates LoRA and the pointer head while the original base matrices remain frozen. Recovery within v4 is a separate operation that restores that interrupted stage’s optimizer and step.

The Pac-Man target is a hard action index in the original legal options. This recipe uses ordinary choice cross-entropy. It does not distill a soft teacher distribution with KL and does not insert a live teacher safety override. Actual learner improvement needs the complete-game evaluation.
