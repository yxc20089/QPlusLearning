What the recorded games teach us

V3 reduced immediately avoidable deaths from 52 to 22, but both students cleared zero games. Food efficiency fell from 46.73 to 34.60 pellets per 1,000 active native frames, and the longest dry interval rose from 131 to 273 decisions. Better immediate avoidance alone did not complete the maze. Different policies visit different states, so these aggregates are behavioral diagnostics, not a same-state causal estimate.

How to evaluate v4 in the notebook

Run the v3–v4 comparison with the completed checkpoints. The cell checks the v3 parent and v4 data manifest, logs active checkpoint identities, evaluates the 512 hard development requests, then runs 20 complete native games per adapter. It also loads an independently replay-verified frozen teacher reference on the same starts. The protocol keeps all four ghost controllers and normal game mechanics. Each intermediate life loss is followed by native continuation if lives remain.

A genuine win is the first level clear. Native game-over ends a losing game. The watchdog bounds are 10,000 decisions, 36,000 active simulation frames, or 512 consecutive decisions without a pellet. A watchdog exit stays in the denominator and is an incomplete failure. Active native frames exclude network/model latency and ready/death animations; measure wall-clock inference latency separately.

The reference suite uses levels 1, 2, 3 and 5 and seeds 50021, 50023, 50033, 50047 and 50051. These are excluded from training, but their past failures informed the data-design discussion. New disjoint starts are needed for a blind test. This classic-maze benchmark does not establish generalization to unseen maze layouts.

Inspect clears, life losses, avoidable immediate deaths, first-life food, pellets per frame, longest dry intervals and loop streaks. Follow up on power-expiry and post-respawn failures in the saved full trajectories. Development agreement, CE and per-role metrics diagnose what the student learned; they do not replace complete-game outcomes.
